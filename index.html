Engineering Stack

Built on Robust Intelligent Technologies

Engineered for sub-second precision, lightweight deployment, and rigorous circular-economy monetization.

MobileNetV2

Real-time waste classification

Inverted residual blocks with linear bottlenecks allow 3.4M parameters to achieve 95.8% multi-class accuracy with minimal memory footprint on edge microcontrollers.

Depthwise Convolutions Sub-50ms Inference 3.4M Parameters

OpenCV

Image enhancement & feature extraction

Adaptive histogram equalization (CLAHE), Otsu thresholding, contour isolation, and background subtraction strip out conveyor belt noise and soiled backgrounds.

CLAHE Normalization ROI Segmentation Edge Detection

TensorFlow

Deep-learning model training & deployment

Trained across 45,000 augmented Indian waste samples, quantized using TFLite Post-Training Quantization (INT8) to reduce model size by 75% without sacrificing recall.

TF Lite Quantization Transfer Learning Cross-Validation

User Flow

How It Works in 4 Steps

Frictionless workflow designed for zero human touchpoints from disposal to circular sale.

01

Capture

Optical sensors or facility cameras capture high-resolution imagery as waste enters the intake chute.

02

Identify

Deep computer vision extracts shape, translucency, and texture features to identify substrate composition.

03

Analyse

System evaluates recyclability grade, detects cross-contamination, and looks up live scrap index pricing.

04

Recommend

AI commands mechanical diverters and dispatches verified recycling routes to circular supply partners.

Strategic Trajectory

Development Roadmap

Our phased execution pathway from SIH 2026 prototype validation to nationwide Smart City rollout.

Completed

Phase 1 — AI Waste Classification

Trained MobileNetV2 architecture with OpenCV image normalization across 45,000 multi-class Indian waste photographs achieving 95.8% validation accuracy.

Active Beta

Phase 2 — Recovery Intelligence

Integrated real-time scrap market value estimation (₹/kg), carbon offset calculations, and automated circular-economy downstream dispatching algorithms.

In Development

Phase 3 — Edge AI with ESP32-CAM

Deploying quantized INT8 TinyML models on low-power microcontrollers with OV2640 camera modules for standalone edge inference in battery-operated bin lids.

Q4 2026 Target

Phase 4 — Smart Bin Integration

Physical fabrication of automated sorting kiosks with dual-axis servo flappers, ultrasonic volume depth sensors, and solar recharging arrays.

2027 Vision

Phase 5 — LoRa Smart-City Network

City-scale LoRaWAN mesh integration linking thousands of smart bins directly to municipal sanitation dispatch centers for dynamic route optimization.
