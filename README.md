# EcoSort AI 🌱♻️
> Intelligent Waste Classification & Resource Recovery | Team NEXTECH 007 (Smart India Hackathon 2026)

EcoSort AI is an AI-powered waste classification, recovery intelligence, and circular-economy decision support system designed to modernize sustainable municipal and industrial resource management.

---

## 🌟 Key Features
- **Intelligent Classification**: Multi-class detection and real-time segmentation of recyclable and compostable waste.
- **Resource Recovery Insights**: Market value estimation, circular economy metrics, and routing recommendations.
- **Interactive Experience**: Interactive live demos, sensor integration diagrams, and community impact calculator.
- **Team NEXTECH 007**: Highlights team members, mentors, and hackathon project milestones.
